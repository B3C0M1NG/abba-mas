# Ecosystem Conformance Boundary V1

ABBA MAS is a capability/orchestration subsystem of ABBA, not a second master intelligence or constitutional layer.

It consumes OMNII universal identity, authority, capability, event, proof and integration contracts and remains replaceable beneath ABBA.

## Rules
- No independent constitutional authority.
- No competing universal identity or value primitive.
- Provider/model choice remains replaceable.
- Human authority is inherited through governed ABBA/HAPI/SEAL crossings.
- Execution preserves provenance, idempotency, proof and bounded delegation.
